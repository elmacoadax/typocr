# typocr
Typocr est un outil de correction de texte. Il corrige des textes venant d’une OCR (reconnaissance de caractères) ou non conformes aux règles.
Il corrige ou signale :
— la typographie : espaces, ponctuation…
— les séparateurs dans les nombres, et les abréviations ;
— les erreurs dues au scan : coupures de lignes ;
— les mots non ordinaires : acronymes.
Ces traitements seront signalés par des colorations dans le texte et insérés au début du texte modifié pour faciliter le travail de correction.
Les fichiers traités au format RTF.
Pour plus de renseignements, consulter le document sur les fonctionnalités.
Typocr est un programme open source, fonctionnant avec Windows, disponible ICI.
